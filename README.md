# LJT-Homepage

Personal homepage of **Junteng Liu**, first-year PhD candidate at HKUST NLP Group.

Built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io), forked from [academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io) and powered by [Jekyll](https://jekyllrb.com/) & GitHub Pages.

## Site structure

- `_pages/about.md` — front page: personal details, academic background, research experience, publications, honors and awards, skills, and contact information
- `_pages/publications.html` + `_publications/` — publications subpage and one Markdown file per publication
- `_config.yml` — site-wide configuration and author sidebar profile
- `_data/navigation.yml` — header navigation
- `_data/authors.yml` — author information
